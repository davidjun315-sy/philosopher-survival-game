# ⚔️ 철학자 생존게임 (Philosopher Survival Game)
> **“끝까지 살아남는 철학자는 누구인가?”**  
> 고등학교 「윤리와 사상」 서양 윤리 입문용 모바일·태블릿 인터랙티브 웹게임

---

## 📖 1. 프로젝트 소개

본 웹게임은 서양 윤리를 처음 접하는 고등학생들이 딱딱한 교과서식 암기 대신, **자신의 직관적인 가치 판단을 통해 나와 가장 생각이 닮은 서양 철학자를 찾아가도록 돕는 입문용 교육 웹게임**입니다.

- **세계관**: 서양 철학자 20명이 한 공간에 모인 가상 세계에 정체불명의 재난이 발생. 15번의 극한 딜레마 상황에서 학생의 선택과 생각이 비슷한 철학자만 살아남아 마지막에 최후의 생존자 1명이 공개됩니다.
- **특징**:
  - 넷플릭스 서바이벌 프로그램 + 밸런스 게임 + RPG 스탯 감성의 몰입형 UI
  - 문제 및 선택지에는 철학자 이름이나 전문 학술 용어를 일절 노출하지 않아 선입견 배제
  - 4, 8, 12라운드마다 서바이벌 긴장감을 높이는 중간 생존 현황판(별명 기반) 연출
  - 15라운드 종료 후 3초 서스펜스 카운트다운 및 최종 생존자(1위), TOP 3, 철학적 천적, 6대 성향 지수 공개
  - 고유 결과 코드(예: `PHIL-KANT-8842`) 및 친구와의 철학적 케미 비교 기능 탑재
  - 서버나 DB가 필요 없는 100% 클라이언트 브라우저 구동 (개인정보 수집 없음)

## 🚀 3. 로컬 실행 및 빌드 방법

### 1) 사전 준비
- [Node.js](https://nodejs.org/) (v18 이상 권장)

### 2) 개발 서버 실행
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev
```
터미널에 표시되는 로컬 주소(기본 `http://localhost:5173`)로 브라우저에서 접속합니다.

### 3) 프로덕션 빌드
```bash
npm run build
```
- `dist/` 폴더에 정적 HTML/CSS/JS 파일이 생성됩니다.
- 별도의 백엔드 없이 GitHub Pages, Vercel, Netlify 등에 바로 업로드하여 서비스할 수 있습니다.

## 🏫 4. 수업 현장 활용 가이드 (교사용)

### ⏱️ 추천 수업 시나리오 (총 45~50분 기준)

1. **도입 (5분) — 호기심 유발 및 접속**
   - 빔프로젝터나 칠판에 웹게임 접속 QR코드/링크를 띄웁니다.
   - *"오늘 우리는 서양 철학자 20명이 모인 서바이벌 공간으로 들어갑니다. 정답은 없습니다. 진짜 내가 할 것 같은 선택을 골라보세요!"*
2. **전개 1: 게임 플레이 (12~15분)**
   - 학생들이 스마트폰이나 태블릿으로 각자 15라운드를 진행합니다.
   - 중간 라운드(4, 8, 12R) 브리핑에서 "누가 살아남고 있냐"며 자연스러운 흥미와 몰입이 형성됩니다.
3. **전개 2: 결과 확인 및 친구 비교 (10분)**
   - 최종 1위 철학자와 6대 성향 그래프를 확인합니다.
   - 옆 짝꿍과 결과 코드를 입력하여 **"우리는 소울메이트인가, 천적인가?"** 케미를 확인하고 대화합니다.
4. **정리: 본 차시 서양윤리 개념 연결 (15분)**
   - 교사는 교과서 목차를 보여주며 설명합니다:
     - *"방금 칸트가 살아남은 사람 손들어 볼까요? 왜 칸트가 나왔을까요? 칸트는 아무리 결과가 좋아도 넘어서는 안 되는 '원칙'을 가장 중요하게 여겼던 사람입니다."*
     - *"반대로 벤담이 나온 친구들은 '최대 다수의 최대 행복'을 선택했기 때문입니다."*
   - '20명 전체 도감' 버튼을 눌러 교과서에 나오는 학파들의 큰 흐름(의무론 vs 공리주의, 이성주의 vs 경험주의, 실존주의 vs 실용주의)을 마인드맵처럼 정리합니다.

## 🌐 6. 배포 가이드

### 1) GitHub Pages 배포
1. 저장소 Settings -> Pages 이동
2. Build and deployment의 Source를 **GitHub Actions**로 선택
3. 정적 사이트 배포 워크플로우를 설정하면 자동으로 `dist` 빌드 산출물이 배포됩니다.

### 2) Vercel 배포
1. [Vercel](https://vercel.com)에 로그인 후 GitHub 저장소 임포트
2. 프레임워크 프리셋을 **Vite**로 선택하고 `Deploy` 클릭
3. 1분 만에 고유 접속 URL(`https://xxx.vercel.app`)이 발급되며 즉시 수업에 사용 가능합니다.
